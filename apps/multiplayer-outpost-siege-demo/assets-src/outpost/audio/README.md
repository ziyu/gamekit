# Outpost Audio Sources

## Magic Space

- Author: CodeManu
- Source: <https://opengameart.org/content/magic-space>
- Download: `magic space.mp3`
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Runtime output: `public/assets/outpost/audio/magic-space.ogg`
- SHA-256: `c87cf01d5ab620d7f4e1898bd125265006d92fe8d60a695f6b3cd21c2d6e1be9`
- Format: stereo Ogg Vorbis, 44.1 kHz, 51.43 seconds
- Runtime edit: the 140 BPM source was rotated and crossfaded over eight beats to create a
  seamless loop, then encoded at approximately 125 kbps.

The track is used as the uplifting Frontier match loop. Attribution is not required by CC0, but
the source and author remain recorded here for provenance.

renamed by gameplay purpose; the original pack filenames and hashes remain recorded below.
