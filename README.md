# GameKit

GameKit 是面向多个独立游戏复用的 TypeScript 游戏框架实验仓库。

当前阶段目标是先完成一条可运行的架构垂直切片：薄内核、ECS facade、Koota adapter、EventBus、GameRuntime、Sandbox。

## 常用命令

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm test
corepack pnpm build
corepack pnpm lint
corepack pnpm bench:world
```
