# GameKit

GameKit 是面向多个独立游戏复用的 TypeScript 游戏框架实验仓库。

## 常用命令

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm test
corepack pnpm build
corepack pnpm lint
corepack pnpm bench:world
```
