# GameKit 文档总览

本文档目录用于沉淀项目设计、实现原则、最佳实践和阶段决策。它不是一次性说明书，而是开发过程中的持续更新资产。

## 文档结构

- `architecture.md`：稳定架构边界、包职责、依赖方向。
- `implementation-principles.md`：写代码时必须遵守的工程原则。
- `best-practices.md`：模块拆分、测试、数据驱动、adapter、UI 等实践规则。
- `development-stages.md`：阶段目标、完成定义、下一阶段入口。
- `adr/`：Architecture Decision Record，记录重要技术决策和取舍。

## 更新规则

每个开发阶段结束前必须检查并补齐：

1. 是否新增或改变了公共 API、包边界、依赖方向。
2. 是否形成了新的最佳实践或反模式。
3. 是否引入了新的第三方库、adapter 或可替换边界。
4. 是否需要新增 ADR 记录不可逆或高影响决策。
5. 是否需要更新下一阶段的完成定义。

文档更新和代码实现同等重要。若实现偏离文档，应优先判断是实现错误，还是文档需要更新。
